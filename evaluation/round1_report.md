## 발견한 문제

- **#14는 "통과"지만 실제로는 콘텐츠 공백이다.** `data/question_bank.json`에 학년·난이도별
  실제 문제가 아직 없어서, 문제은행 대체가 필요한 날 아이에게 줄 문제가 0개가 될 수 있다.
  SERVICE.md 4번 정책(문제은행에서 대체)을 실질적으로 만족하려면 최소한 자녀가 실제
  쓰는 학년·난이도 조합에는 문제를 채워둬야 한다.
- 평가는 HTTP 계층(`POST /query`)이 아니라 내부 함수를 직접 호출해 실행했다. API
  계층(요청 검증·에러 응답 형식 등)은 별도로 확인이 필요하다.
